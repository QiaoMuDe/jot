# 向量索引弹窗范围切换过渡动画优化

## 摘要

数据管理页面「AI 量化索引」弹窗（笔记量化弹窗）中，切换「全部笔记 / 指定笔记本 / 指定笔记」三种范围时，分段指示条已有平滑滑动动画，但下方的笔记本/笔记选择区目前是 `style.display` 瞬间切换，观感割裂。本计划为选择区补上进入/退场过渡动画，沿用弹窗内已有的 select↔progress 视图两阶段动画模式（`view-enter` / `view-leave`），并处理动画定时器与视图切换/关闭弹窗之间的边界，保证无残留状态。

## 现状分析

- 弹窗结构（`frontend/index.html` L1990-L2067）：分段控件 `vectorIndexScopeSeg` + 两个选择区 `vectorIndexNotebookPicker` / `vectorIndexNotePicker`，均使用 `style="display:none"` 初始隐藏。
- 切换逻辑（`frontend/src/js/data-management.js` 的 `switchVectorIndexScope`，L744-L760）：
  - 更新分段按钮 `.active`；
  - 调用 `repositionVectorIndexScopeIndicator()` 移动指示条（CSS 已用 `transition: left/width 0.22s spring` 平滑，见 `data-view.css` L657-L669）；
  - **选择区直接 `style.display = '' / 'none'` 瞬间切换，无动画** —— 这是本次要优化的点。
- 可复用模式：`setVectorIndexView`（L717-L738）已实现两阶段动画：旧视图加 `view-leave` 退场 170ms → `display:none` → 新视图加 `view-enter` 入场 220ms → 移除 class。对应 CSS 在 `data-view.css` L627-L643。
- 无障碍：`data-view.css` L1150-L1165 已有 `prefers-reduced-motion: reduce` 块，需把新增动画类一并纳入禁用。
- 其他相关入口：
  - `openVectorIndexModal`（L627-L630）打开时把两个选择区重置为 `display:none`；
  - `closeVectorIndexModal`（L664-L681）关闭时清理 `vectorIndexChunkResetTimer`；
  - 模块级状态变量区在 L517-L525。

## 变更方案

### 1. `frontend/src/css/components/data-view.css`

在 `.vector-index-picker`（L698-L705）之后新增两个动画类与 keyframes：

- `.vector-index-picker.picker-leave`：`animation: vectorIndexPickerLeave 0.15s ease-in forwards;`
- `.vector-index-picker.picker-enter`：`animation: vectorIndexPickerEnter 0.2s var(--anim-easing-spring) forwards;`
- `@keyframes vectorIndexPickerLeave`：`to { opacity: 0; transform: translateY(-6px); }`
- `@keyframes vectorIndexPickerEnter`：`from { opacity: 0; transform: translateY(8px); }` → `to { opacity: 1; transform: translateY(0); }`

选择淡入 + 轻微垂直位移动画：与视图切换动画节奏一致（退场 150ms / 入场 200ms spring），比水平滑动更通用（无需按方向区分左右），也不会与指示条的水平滑动冲突。

在 `prefers-reduced-motion: reduce` 块（L1150-L1165）中追加 `.vector-index-picker.picker-leave` 与 `.vector-index-picker.picker-enter`。

### 2. `frontend/src/js/data-management.js`

在模块级状态变量区（L517-L525 附近）新增：

```js
let vectorIndexPickerTimer = null; // 选择区切换动画定时器（防止动画中断残留状态）
```

新增辅助函数（放在 `switchVectorIndexScope` 之前）：

```js
/**
 * 选择区进入/退场动画：先让旧选择区退场（150ms），再展示新选择区并入场（200ms）
 * @param {HTMLElement|null} showEl - 要展示的选择区；null 表示无（切到「全部笔记」）
 * @param {HTMLElement|null} hideEl - 当前可见的选择区；null 表示当前无可见选择区
 */
function animateVectorIndexPicker(showEl, hideEl) {
    if (vectorIndexPickerTimer) { clearTimeout(vectorIndexPickerTimer); vectorIndexPickerTimer = null; }
    // 快速路径：目标与当前一致（或均为空），无需动画
    if (showEl === hideEl) return;
    const done = () => {
        if (hideEl) { hideEl.style.display = 'none'; hideEl.classList.remove('picker-leave'); }
        if (showEl) {
            showEl.style.display = '';
            showEl.classList.remove('picker-leave');
            showEl.classList.add('picker-enter');
            vectorIndexPickerTimer = setTimeout(() => {
                showEl.classList.remove('picker-enter');
                vectorIndexPickerTimer = null;
            }, 220);
        }
    };
    if (!hideEl || hideEl.style.display === 'none') {
        // 旧选择区不可见：直接展示新的并入场
        done();
        return;
    }
    // 旧选择区可见：先退场再展示新的
    hideEl.classList.add('picker-leave');
    vectorIndexPickerTimer = setTimeout(() => {
        vectorIndexPickerTimer = null;
        done();
    }, 150);
}
```

修改 `switchVectorIndexScope`（L744-L760）：把两处 `style.display` 直接赋值替换为调用 `animateVectorIndexPicker(showEl, hideEl)`：

- 计算 `target = scope === 'notebooks' ? nbPicker : scope === 'notes' ? ntPicker : null`；
- 计算当前可见选择区 `visible = (ntPicker.style.display !== 'none') ? ntPicker : ((nbPicker.style.display !== 'none') ? nbPicker : null)`（两个选择区互斥，最多一个可见）；
- 调用 `animateVectorIndexPicker(target, visible)`，其余逻辑（按钮高亮、指示条、清空已选、计数更新）保持不变。

补充两处定时器清理，防止动画中途被其他操作打断导致 display 状态错乱：

- `setVectorIndexView`（L717-L738）开头：若 `vectorIndexPickerTimer` 存在则 `clearTimeout` 并置空（点击「开始量化」切入进度视图时，取消未完成的选择区动画）。
- `closeVectorIndexModal`（L664-L681）中，在清理 `vectorIndexChunkResetTimer` 处同步清理 `vectorIndexPickerTimer`。

### 3. 明确不做（避免过度设计）

- 不添加列表项 stagger 淡入、计数文字淡入等锦上添花效果；
- 不自动聚焦搜索框（行为改动超出本次动画需求，且可能影响原有交互预期）。

## 假设与决策

- 动画方向采用「淡入 + 垂直位移」，不区分切换左右方向，保持实现简单且与指示条水平滑动视觉不冲突。
- 退场 150ms / 入场 200ms 与现有视图动画时长一致（170ms / 220ms），保持整体节奏统一。
- 两个选择区互斥可见，切到「全部笔记」时仅执行退场、无入场。
- 打开弹窗时 `openVectorIndexModal` 原有的 `display:none` 重置逻辑保持不变，无需改动（动画 class 均会在动画结束后移除，且每次进入时选择区处于隐藏态）。

## 验证步骤

1. `cd frontend && npm run build`，确认 JS/CSS 无编译错误。
2. 运行应用（`wails dev` 或构建产物），打开「数据管理 → AI 量化索引」弹窗：
   - 全部笔记 ↔ 指定笔记本 ↔ 指定笔记 三向反复切换，确认选择区有平滑淡入/退场动画，指示条滑动与内容切换节奏协调；
   - 快速连续点击切换，确认无残留（选择区不出现「显示状态错乱 / 两个同时显示 / 永久空白」）。
3. 切换范围后点击「开始量化」，确认视图切入进度视图正常，无选择区动画残留。
4. 量化进行中关闭弹窗（或切换范围后直接关闭弹窗），确认无报错、定时器无残留。
5. 系统开启「减少动态效果」（prefers-reduced-motion）后重测切换，确认动画被禁用、切换即时生效。
