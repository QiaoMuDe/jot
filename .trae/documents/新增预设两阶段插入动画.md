# 新增预设两阶段插入动画

## 问题

当前新增动画：新行以完整高度 `translateX(-30px) → 0` 滑入。由于行已有完整高度，插入瞬间将其下方现有行整体挤下，这个位移是瞬时的，毫无过渡。用户期望的是**空间先平滑展开，内容随后滑入**。

## 方案

将 `preset-row-enter-left` 替换为两阶段动画 `preset-row-insert`：

**阶段 1（0-30%，≈105ms）**：`max-height` 从 0 → 行高，padding 恢复，撑开空间，下方行被平滑推下  
**阶段 2（30-100%，≈245ms）**：`opacity` + `transform` 从左滑入到位，内容显现

### 1. CSS：替换动画定义

替换 [settings-panel.css](file:///d:/峡谷/Dev/本地项目/jot/frontend/src/css/components/settings-panel.css#L1273-L1287) 中的 `preset-row-enter-left`：

```css
/* 新增预设行插入动画：先展开空间，再滑入内容 */
.preset-row-insert {
    animation: presetRowInsert 350ms ease-out both;
    overflow: hidden;
}

@keyframes presetRowInsert {
    0% {
        max-height: 0;
        opacity: 0;
        transform: translateX(-30px);
        padding-top: 0;
        padding-bottom: 0;
    }
    30% {
        max-height: 80px;   /* 空间展开完毕 */
        opacity: 0;
        transform: translateX(-30px);
        padding-top: 6px;
        padding-bottom: 6px;
    }
    100% {
        max-height: 80px;
        opacity: 1;
        transform: translateX(0);
        padding-top: 6px;
        padding-bottom: 6px;
    }
}
```

### 2. JS：先设初始态，再触发动画

替换 [main.js](file:///d:/峡谷/Dev/本地项目/jot/frontend/src/main.js#L2998-L3010) 中新增行的动画逻辑：

```javascript
const row = createPresetRowElement(profile);
// 初始态：零高度、透明、左侧偏移
row.style.maxHeight = '0';
row.style.overflow = 'hidden';
row.style.opacity = '0';
row.style.transform = 'translateX(-30px)';
row.style.paddingTop = '0';
row.style.paddingBottom = '0';

// 插入到标题栏之后（此时行不占可见空间）
const header = presetMgrContainer.firstElementChild;
if (header) {
    header.after(row);
} else {
    presetMgrContainer.appendChild(row);
}

// 下一帧触发动画
requestAnimationFrame(() => {
    row.classList.remove('preset-row-enter');
    row.classList.add('preset-row-insert');
});

// 动画结束后清理 inline 覆盖，恢复由 cssText 控制
row.addEventListener('animationend', () => {
    row.style.maxHeight = '';
    row.style.overflow = '';
}, { once: true });
```

### 3. 无需改动的部分

- 删除动画 `preset-delete-out` 完全不变
- `renderPresetMgrList` 全量渲染继续使用 `preset-row-enter`（上方位移淡入）
- 后端、HTML 均无改动

## 视觉流程

```
时间轴：0ms ─────────────────────────────────── 350ms
       ┌────────────┬──────────────────────────────┐
       │  阶段 1     │  阶段 2                      │
       │  max-height │  opacity + translateX        │
       │  0 → 80px   │  0 → 1 , -30px → 0          │
       │  padding    │  (内容从左滑入)               │
       │  恢复       │                              │
       │  (空间展开)  │                              │
       └────────────┴──────────────────────────────┘
       0ms         105ms                         350ms
```

## 验证步骤

1. 展开管理列表（列表有 3+ 行数据）
2. 新增预设并保存
3. 观察：下方行被平滑推下（空间展开）→ 新行从左滑入
4. 验证无闪烁，动画结束后高度/内边距正常
