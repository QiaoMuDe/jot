# 增加截图展示区域 —— 实施计划

## 概述

在 Jot 落地页的「特性」与「技术栈」之间，新增一个**截图展示区**（Screenshots Gallery），图片数据通过 JSON 配置文件管理，方便后续增删维护。

***

## 当前状态分析

* **index.html**: 271 行，包含 Hero / 特性 / 技术栈 / 统计 / CTA / 页脚 6 个区块

* **css/style.css**: 524 行，按区块组织，无图片相关样式

* **js/main.js**: 90 行，功能：导航滚动、入场动画、计数器、锚点滚动

* 站点无任何图片目录和媒体资源

***

## 实施步骤

### Step 3: 修改 index.html

在「特性」section 之后、「技术栈」section 之前，新增截图展示 section：

```html
<!-- ========== Screenshots ========== -->
<section id="screenshots">
  <div class="section-header reveal">
    <span class="section-label">Screenshots</span>
    <h2 class="section-title">界面预览</h2>
    <p class="section-desc">一图胜千言，看看 Jot 的真实面貌</p>
  </div>
  <div class="screenshots-grid reveal" id="screenshots-grid">
    <!-- JS 动态渲染 -->
  </div>
  <!-- 图片放大查看 Lightbox -->
  <div class="lightbox" id="lightbox">
    <span class="lightbox-close">&times;</span>
    <img class="lightbox-img" id="lightbox-img" src="" alt="">
    <div class="lightbox-caption" id="lightbox-caption"></div>
  </div>
</section>
```

同时在导航栏添加一个`截图`链接：

```html
<a href="#screenshots">截图</a>
```

### Step 4: 修改 css/style.css

新增截图展示区样式（约 120 行）：

* **screenshots-grid**: 2 列网格布局（minmax(400px, 1fr)），响应式降为单列

* **screenshot-card**: 毛玻璃卡片风格，与现有特性卡片风格一致，hover 浮起 + 阴影

* **screenshot-card img**: 圆角 12px，宽高比 16:9，object-fit: cover，块级显示

* **screenshot-card .caption**: 底部文字说明，半透明底色

* **lightbox**: 固定定位全屏遮罩，居中显示图片，点击关闭/按 ESC 关闭

* 入场动画复用现有的 `.reveal` 类

### Step 5: 修改 js/main.js

新增截图动态渲染逻辑（约 40 行）：

```javascript
/* ========== 截图动态渲染 ========== */
fetch('media.json')
  .then(function(res) { return res.json(); })
  .then(function(data) {
    var grid = document.getElementById('screenshots-grid');
    data.screenshots.forEach(function(item) {
      var card = document.createElement('div');
      card.className = 'screenshot-card';
      card.innerHTML = '<img src="' + item.src + '" alt="' + item.alt + '" loading="lazy">' +
        '<div class="screenshot-caption">' +
        '<strong>' + item.alt + '</strong>' +
        '<span>' + item.caption + '</span>' +
        '</div>';
      // 点击放大
      card.addEventListener('click', function() {
        document.getElementById('lightbox-img').src = item.src;
        document.getElementById('lightbox-caption').textContent = item.alt;
        document.getElementById('lightbox').classList.add('active');
      });
      grid.appendChild(card);
    });
    // 重新观察新插入的 .reveal 元素
    grid.classList.add('visible');
  });

/* ========== Lightbox 控制 ========== */
document.getElementById('lightbox').addEventListener('click', function(e) {
  if (e.target === this || e.target.classList.contains('lightbox-close')) {
    this.classList.remove('active');
  }
});
document.addEventListener('keydown', function(e) {
  if (e.key === 'Escape') {
    document.getElementById('lightbox').classList.remove('active');
  }
});
```

### Step 6: 更新 serve.py 的 MIME 支持

Python `http.server` 默认支持 `.json` 的 MIME 类型，无需额外配置。

## 设计决策

| 决策       | 选择                          | 理由                                            |
| -------- | --------------------------- | --------------------------------------------- |
| 图片数据源    | JSON 配置文件                   | 纯前端，零依赖，增删改只需改 JSON                           |
| 图片加载     | 原生 `<img>` + loading="lazy" | 无需额外库，懒加载性能好                                  |
| 图片放大     | 自定义 Lightbox（纯 CSS/JS）      | 无需引入第三方库，保持轻量                                 |
| 占位图      | 使用 placeholder.com 在线服务     | 无需真实截图即可开发，后续替换为真实截图                          |
| 布局       | 2 列网格                       | 截图宽度较大，2 列比 3 列更清晰                            |
| 与现有风格一致性 | 毛玻璃卡片 + 弹性缓动                | 复用现有的 `--ease-spring`、`--radius`、`.reveal` 动画 |
