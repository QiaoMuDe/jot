# 工具调用信息折叠化 + 附录化重构

## Summary

将 AI 消息中的"工具调用状态条/工具链"从"正文上方、一直展开"改为 **A+B 方案**（用户已选定）：

1. **进行中**：仍显示在正文上方（思维链下）实时反馈，脉冲动画提示"正在搜索/正在检索…"——不丢失实时反馈。
2. **完成后**：上方实时工具条**移除**，改为在**正文下方**（搜索来源面板、召回卡片面板之后）渲染一个**默认折叠的工具摘要组件**：一行摘要（图标 + 「已调用 N 个工具」+ 可选失败徽标），点击展开明细列表。
3. **历史回放与实时完成态统一**：同一折叠组件、同一位置。

仅改前端两个文件，后端事件与数据结构零改动。

* 工具链（过程/日志信息）与正文同级长期展开，多工具调用时气泡被拉长，正文被推挤，视觉噪音大。

## Proposed Changes

### 1. `frontend/src/js/ai-chat.js`

**a. 重构** **`renderToolCalls(el, toolCalls)`** **为折叠组件**（L3991-4067 整函数重写）：

* **摘要统计**：遍历 `toolCalls`（跳过非 `tool_start`），统计

  * `total`：工具调用总次数（tool\_start 条数）

  * `failedNames` / `partialNames`：tool\_error / tool\_partial 对应的工具名集合（现有逻辑保留）

  * `failCount` = failedNames 大小；`partialCount` = partialNames 大小

* **组件结构**（追加到 `el` 末尾，不再 insertBefore 到正文上方）：

```html
<div class="ai-tool-summary">
  <button type="button" class="ai-tool-summary-toggle" aria-expanded="false"
          aria-controls="ai-tool-detail-{uid}">
    <svg wrench 14px/>                       <!-- svgIcon('wrench') -->
    <span class="ai-tool-summary-text">已调用 3 个工具</span>
    <span class="ai-tool-summary-status is-error">1 失败</span>  <!-- 仅失败/部分失败时显示 -->
    <svg chevron-down 14px/>                 <!-- svgIcon('chevron') -->
  </button>
  <div class="ai-tool-summary-detail" id="ai-tool-detail-{uid}">
    <div class="ai-tool-status-list">…现有明细渲染逻辑（is-error/is-warning/is-done + svgIcon）…</div>
  </div>
</div>
```

* **摘要文案**：`已调用 {total} 个工具`（全部成功）；有失败 → 追加徽标 `{failCount} 失败`（is-error）；有部分失败 → 追加徽标 `{partialCount} 来源不可用`（is-warning）。

* **交互**：toggle 的 `click` 与 `keydown`（Enter/Space）切换 `aria-expanded`（true/false）并切换 detail 的展开 class（如 `.open`）；`{uid}` 用 `Date.now()` 保证 id 唯一。

* **删除** L4060-4066 的 `insertBefore(list, contentEl)` 逻辑，改为 `el.appendChild(summary)`。

* **新增** **`svgIcon('wrench')`** **/** **`svgIcon('chevron')`** **路径**：在 `svgIcon` 的 `paths` 表（L2957-2963）追加：

## Assumptions & Decisions

1. **位置**：完成态折叠组件放正文下方（搜索来源、召回卡片之后），与"答案 > 依据 > 过程"层级一致；进行中仍在上方实时反馈。
2. **默认收起**：完成后默认折叠（渐进披露）；点击/键盘展开明细。
3. **摘要文案**：主文案「已调用 N 个工具」；失败徽标「M 失败」（danger），部分失败徽标「M 来源不可用」（warning），全部成功不显示徽标。
4. **明细内容不变**：保留现有 ✅/❌/⚠️ SVG 状态项与文案（web\_search/recall\_notes/refine\_search\_query 名称映射）。
5. **不改变后端**：`tool_calls` 数据结构、事件、落库均不变；仅前端展示层调整。
6. 交互满足可访问性：`button` 原生语义 + `aria-expanded` + `aria-controls`；键盘 Enter/Space 可展开。
7. 动画遵循 class-driven + `prefers-reduced-motion` 降级。

## Verification

1. 重新构建运行（`wails dev` 或前端构建），诊断无报错（GetDiagnostics）。
2. **Agent 模式进行中**：提问触发工具 → 正文上方出现脉冲"正在搜索/正在检索…"实时条。
3. **完成态**：流结束后上方实时条消失；正文下方（来源/卡片之后）出现折叠摘要「已调用 N 个工具」；点击展开明细（✅/❌/⚠️），再点收起；键盘 Enter/Space 同样可切换。
4. **失败/部分失败**：key 错误触发失败 → 摘要显示「M 失败」徽标（红色）；部分来源失败 → 「M 来源不可用」（黄色）。
5. **历史回放**：切换会话重新加载 → 折叠摘要位于正文下方、与实时完成态形态一致，展开明细正确。
6. **无障碍**：开启"减少动态效果"后展开动画为瞬时切换、无过渡；按钮可用 Tab 聚焦。
