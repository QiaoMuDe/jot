# 预设编辑保存后管理列表行不更新的问题修复

## 当前状态分析

编辑预设配置后保存，管理列表中的对应条目行数据仍然是旧的。再次点击该行的「编辑」按钮，弹窗各字段为空。

**根因**：`savePresetModal` 中编辑保存后只调了 `loadProfiles()`（仅刷新下拉菜单），没有刷新管理列表的行。管理列表每行由 `createPresetRowElement(p)` 创建，编辑按钮的 `click` 回调通过闭包捕获当时传入的 p 对象。保存后闭包数据未更新，再次点击编辑时 `openEditProfileModal` 拿到的是旧数据。

**相关代码位置**：
- [main.js#L3008-L3071](frontend/src/main.js#L3008-L3071) - `savePresetModal`（保存函数）
- [main.js#L3158-L3208](frontend/src/main.js#L3158-L3208) - `createPresetRowElement`（行创建）
- [main.js#L2974-L2999](frontend/src/main.js#L2974-L2999) - `openEditProfileModal`（打开编辑弹窗）
- [main.js#L3002-L3005](frontend/src/main.js#L3002-L3005) - `closePresetModal`（关闭弹窗，重置 `editingProfileId`）

## 修改方案

不重构整个列表，而是精准替换编辑对应的那一行。纯前端改动。

### 步骤

#### Step 1: 管理列表行添加 dataset 标记

**文件**：[frontend/src/main.js](frontend/src/main.js) — `createPresetRowElement` 函数

在 `createPresetRowElement` 中给 row 元素添加 `data-profile-id` 属性：

```javascript
row.dataset.profileId = p.id;
```

这是后续精准定位行的依据。

#### Step 2: 编辑保存后精准替换行

**文件**：[frontend/src/main.js](frontend/src/main.js) — `savePresetModal` 函数

在 `closePresetModal()` 之前保存编辑状态。保存成功后，如果是编辑模式且管理列表已展开，执行以下操作：

1. 从表单字段构造更新后的 profile 对象：`{ id: editingProfileId, name, provider, baseURL, apiKey }`
2. 通过 `presetMgrContainer.querySelector(`[data-profile-id="…"]`)` 找到旧行
3. 如果找到，调用 `createPresetRowElement(updatedProfile)` 创建新行，`replaceWith` 替换之
4. 新行的入场动画借用 `preset-row-insert` 类给出微弱的视觉反馈

### 涉及文件

仅 [frontend/src/main.js](frontend/src/main.js) — `createPresetRowElement` 加一行 + `savePresetModal` 加约 10 行。

### 验证方法

1. 打开设置 → API 连接 → 预设管理
2. 点「编辑」打开任意预设，修改名称/地址/key，保存
3. 再次点该行的「编辑」，弹窗字段显示最新保存的值
4. 管理列表行显示的名称和地址也是最新的
