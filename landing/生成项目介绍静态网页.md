## 方案对比

### 方案 1：JSON 配置文件（推荐）

在 `landing/` 下新建一个 `media.json`，用一个数组管理所有图片/视频：

```json
{
  "screenshots": [
    { "src": "images/screenshot-01.png", "alt": "笔记网格", "caption": "卡片式笔记网格" },
    { "src": "images/screenshot-02.png", "alt": "AI 助手", "caption": "AI 智能对话" }
  ],
  "videos": [
    { "src": "videos/demo-01.mp4", "alt": "操作演示", "poster": "images/poster-01.png" }
  ]
}
```

**操作方式**：增加/删除图片 → 改 JSON 中的条目即可，**不动 HTML/CSS/JS**。JS 读取 JSON 动态渲染图片区域。

### 方案 2：纯目录扫描（最简单）

在 `landing/` 下建一个 `images/` 目录，把图片按约定命名放进去（如 `screenshot-01.png`、`screenshot-02.png`）。JS 自动扫描目录下的文件列表来渲染。

**操作方式**：往 `images/` 丢文件或删文件即可，**连 JSON 都不用改**。但需要后端配合返回目录文件列表，或者在前端硬编码一个约定的文件名列表。

### 方案 3：Markdown 清单

在 `landing/` 下建一个 `media-list.md`，用 Markdown 列表管理：

```markdown
- screenshot-01.png | 笔记网格
- screenshot-02.png | AI 助手
- video-01.mp4 | 操作演示
```

**操作方式**：改 Markdown 即可，但解析需要额外处理。
