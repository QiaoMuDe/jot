# 调整日历视图左右分栏比例

## 背景

程序窗口初始宽度和高度已调整（当前 1280x800），日历视图左侧日历面板固定 `width: 340px`，右侧笔记列表面板 `flex:1` 占满剩余空间。固定宽度在窗口缩放或全屏时无法自适应，导致布局比例不协调。

## 目标

将左右分栏从固定宽度改为**比例（flex）布局**，使窗口大小变化时两侧按比例自适应。

## 方案

### 修改文件

**`frontend/src/css/components/calendar.css`**（第 30-38 行）

```css
/* 修改前 */
.calendar-sidebar {
    width: 340px;
    flex-shrink: 0;
    padding: 20px 16px;
    display: flex;
    flex-direction: column;
    gap: 16px;
    border-right: 1px solid var(--border);
}

/* 修改后 */
.calendar-sidebar {
    flex: 3;
    min-width: 340px;
    padding: 20px 16px;
    display: flex;
    flex-direction: column;
    gap: 16px;
    border-right: 1px solid var(--border);
}
```

改动点：

1. `width: 340px` → `flex: 3`：按比例分配空间（3 份）
2. `flex-shrink: 0` → 删除：不再需要禁用缩小
3. 新增 `min-width: 340px`：保证窗口极窄时日历仍可正常显示

**同文件**（第 171-179 行）右侧笔记面板无需修改，已经使用 `flex: 1`。

### 比例说明

| 面板                             | flex 值    | 实际占比  | 1280px 窗口下约宽度 |
| ------------------------------ | --------- | ----- | ------------- |
| 左侧日历 (`.calendar-sidebar`)     | `flex: 3` | 37.5% | \~410px       |
| 右侧笔记 (`.calendar-notes-panel`) | `flex: 1` | 62.5% | \~682px       |

窗口全屏（如 1920px）时，左侧约 616px，右侧约 1296px，比例保持不变。

## 验证

1. 运行 `wails dev` 启动应用
2. 切换到日历视图，确认左侧日历面板宽度增大、右侧不再过于空旷
3. 将窗口拉到全屏，确认左右比例保持一致、布局自适应
4. 将窗口缩小到较小尺寸，确认左侧日历面板不会过度压缩（min-width 保护）
