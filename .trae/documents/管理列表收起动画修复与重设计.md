# 管理列表收起动画修复与重设计

## 当前状态分析

### 问题根因
管理列表的收起动画（`mgrSlideUp`）从未正常播放过。**根因在 CSS 层面**：

- 基础类 `.preset-mgr-list` 自带 `animation: mgrSlideDown 250ms ease-out both`
- 关闭时添加 `.preset-mgr-list.closing` 切换为 `animation: mgrSlideUp 200ms ease-in both`

CSS 规范缺陷：当元素已有的 animation 完成并处于 `fill-mode: both` 保留态后，仅通过修改 `animation-name`（或 shorthand）不会可靠地触发新动画播放。各浏览器对此行为不一致，实际表现为关闭时直接消失无动画。

### 相关文件
- **[settings-panel.css](frontend/src/css/components/settings-panel.css#L1073-L1109)**：`.preset-mgr-list`（自带 mgrSlideDown）、`.preset-mgr-list.closing`（mgrSlideUp）、`@keyframes mgrSlideDown/mgrSlideUp`
- **[main.js](frontend/src/main.js#L3110-L3128)**：`renderPresetMgrList()` 创建容器时直接设置 `className='preset-mgr-list'`
- **[main.js](frontend/src/main.js#L3225-L3236)**：`closePresetMgrList()` 添加 `closing` class 并监听 `animationend`
- **[scrollbar.css](frontend/src/css/scrollbar.css)**：`.preset-mgr-list` 滚动条样式

## 修改方案

### Step 1: CSS 改动 — 动画从 base class 剥离，通过独立 class 触发

**文件**：[settings-panel.css](frontend/src/css/components/settings-panel.css)

**改动**：
1. 从 `.preset-mgr-list` 移除 `animation: mgrSlideDown ...`，使元素默认无动画
2. 新增 `.preset-mgr-list.open` 触发入场动画
3. 重设计关闭动画 `@keyframes mgrSlideUp`：
   - 加入 `transform-origin: top center` 让容器从底部向上"吸"
   - 加入 `scaleY(1) → scaleY(0.95)` 轻微"挤压"感
   - 加入 `filter: blur(0) → blur(2px)` 散景模糊
   - `opacity: 1 → 0`
   - `max-height: 500px → 0`
   - `padding-top/padding-bottom: 12px → 0`（同步压缩 padding）
   - 时长从 200ms 延长到 250ms，配合 `ease-in-out` 曲线

```css
.preset-mgr-list {
    /* 移除了 animation */
    margin-bottom: 16px;
    max-height: 500px;
    overflow-y: auto;
}
.preset-mgr-list.open {
    animation: mgrSlideDown 250ms ease-out both;
}
.preset-mgr-list.closing {
    animation: mgrSlideUp 280ms ease-in-out both;
    transform-origin: top center;
}
@keyframes mgrSlideUp {
    from {
        opacity: 1;
        transform: scaleY(1);
        filter: blur(0);
        max-height: 500px;
        padding-top: 12px;
        padding-bottom: 12px;
    }
    to {
        opacity: 0;
        transform: scaleY(0.95);
        filter: blur(2px);
        max-height: 0;
        padding-top: 0;
        padding-bottom: 0;
    }
}
```

### Step 2: JS 改动 — 创建容器后添加 `.open` class

**文件**：[main.js](frontend/src/main.js) — `renderPresetMgrList()`

在容器创建并插入到 DOM 后，通过 `requestAnimationFrame` 添加 `.open` class 触发入场动画：

```javascript
// renderPresetMgrList 中，在 presetRow.after(presetMgrContainer) 后
requestAnimationFrame(() => {
    presetMgrContainer.classList.add('open');
});
```

### Step 3: JS 改动 — `closePresetMgrList` 移除 `.open` class

**文件**：[main.js](frontend/src/main.js) — `closePresetMgrList()`

关闭时先移除 `.open` 再添加 `.closing`，确保动画状态干净：

```javascript
presetMgrContainer.classList.remove('open');
presetMgrContainer.classList.add('closing');
```

### 涉及文件
- [frontend/src/css/components/settings-panel.css](frontend/src/css/components/settings-panel.css) — 拆离 base animation + 重设计 mgrSlideUp
- [frontend/src/main.js](frontend/src/main.js) — renderPresetMgrList 加 open class + closePresetMgrList 移除 open

### 验证方法
1. 打开设置 → API 连接 → 点「管理」→ 列表展开（mgrSlideDown 动画）
2. 点「关闭」按钮 → 列表以挤压 + 模糊 + 淡出动画收起（280ms）
3. 再次点「管理」→ 重新展开
4. 展开后点预设下拉菜单触发器 → 列表先播关闭动画，完成后下拉展开
