# Checklist

- [x] `FindByTitleAndExt` 方法按标题+后缀+笔记本查询，能正确返回匹配笔记或 nil
- [x] 无匹配笔记时导入行为不变（创建新笔记，status 为 "created"）
- [x] 有匹配笔记且文件更新时，笔记内容被覆盖，status 为 "updated"，不创建新笔记
- [x] 有匹配笔记且笔记更新时，返回 status 为 "conflict"，附带正确的时间戳
- [x] 时间相同时返回 status 为 "skipped"，不创建也不覆盖
- [x] `ResolveImportConflict(noteID, true)` 正确覆盖笔记内容
- [x] `ResolveImportConflict(noteID, false)` 不修改笔记，返回成功
- [x] 冲突弹窗顶部显示"发现 N 个冲突文件"
- [x] 冲突弹窗每项显示文件名、笔记标题、笔记时间、文件时间
- [x] 冲突弹窗每项提供"覆盖"和"保留"按钮
- [x] 点击单个"覆盖"按钮后该项从列表移除，笔记被覆盖
- [x] 点击单个"保留"按钮后该项从列表移除，笔记不变
- [x] "全部覆盖"快捷按钮一次性覆盖所有冲突项
- [x] "全部保留"快捷按钮一次性跳过所有冲突项
- [x] 全部项处理完后弹窗自动关闭
- [x] 冲突弹窗关闭后笔记列表和侧边栏正确刷新
- [x] 不同笔记本中的同名文件互不影响
- [x] 导入后笔记的 `UpdatedAt` 正确更新为当前时间
