# 修复预设弹窗点击空白处误关闭（无未保存修改判断）

## Summary

API 配置预设弹窗（新增/编辑）在用户编辑了内容后，点击遮罩空白处、右上角 ×、取消按钮或按 ESC，都会无判断地直接关闭弹窗，导致已编辑内容全部丢失，用户需要重新编辑。

本次修改：打开弹窗时记录表单初始快照；关闭时若有未保存修改，先弹出确认框（使用项目已有 `showConfirmDialog`），用户确认后才真正关闭；保存成功后的程序化关闭不受影响。

## Proposed Changes

全部改动集中在 `frontend/src/main.js`，共 3 处：

### 1. 新增初始快照变量

在 `let editingProfileId = null;`（L3057）附近新增：

```js
// 预设弹窗打开时的表单初始值快照（用于判断是否有未保存修改）
let presetModalInitial = { name: '', url: '', key: '' };
```

### 2. 打开弹窗时记录快照

在 `openAddProfileModal`（L3150）与 `openEditProfileModal`（L3172）中，完成表单填充（含 Key 显示/隐藏重置）之后、`overlay.classList.add('visible')` 之前，记录快照：

```js
presetModalInitial = {
    name: document.getElementById('presetModalName').value,
    url: document.getElementById('presetModalURL').value,
    key: document.getElementById('presetModalKey').value,
};
```

### 3. 关闭时判断是否有修改

修改 `closePresetModal`（L3194）：

```js
// 关闭预设弹窗；force 为 true 时跳过未保存修改确认（保存成功后使用）
async function closePresetModal(force = false) {
    if (!force && hasPresetModalChanges()) {
        const ok = await showConfirmDialog('有未保存的修改，确定放弃并关闭吗？');
        if (!ok) return;
    }
    document.getElementById('presetModalOverlay').classList.remove('visible');
    editingProfileId = null;
}

// 判断预设弹窗表单是否相对初始快照有修改
function hasPresetModalChanges() {
    const g = (id) => (document.getElementById(id)?.value ?? '');
    return g('presetModalName') !== presetModalInitial.name
        || g('presetModalURL') !== presetModalInitial.url
        || g('presetModalKey') !== presetModalInitial.key;
}
```

修改 `savePresetModal`（L3229）中的调用：

```js
closePresetModal();  // 改为
closePresetModal(true);  // 保存成功后跳过确认，避免保存后还需再确认
```

## Assumptions & Decisions

* 关闭入口（遮罩、×、取消、ESC）均保持调用无参 `closePresetModal()`，统一走"有修改则确认"逻辑；仅保存成功后传 `true` 跳过。

* 使用项目已有的 `showConfirmDialog`，不新增 UI 组件。

* 修改判断按"当前输入框值 ≠ 初始快照"的字符串比较，无需 focus/blur 或脏标记，最简可靠。

* 关闭后无需重置快照（下次打开会重新记录）。

## Verification

1. 新增预设：编辑名称/URL/Key 后点遮罩空白处 → 应弹出"有未保存的修改"确认框；取消则保持弹窗和内容，确定则关闭。
2. 新增预设：不做任何修改点遮罩/×/取消/ESC → 直接关闭，无确认框。
3. 编辑已有预设：修改内容后按 ESC / 点 × / 点取消 → 弹出确认框。
4. 保存（含 Enter 保存）：点击保存或按 Enter → 保存成功直接关闭，不出现确认框。
5. 保存后重新打开同一预设 → 表单值与保存值一致，点遮罩直接关闭（无残留脏标记）。
