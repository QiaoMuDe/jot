# 修复：编辑器操作按钮在预览模式下应隐藏

## 概述

用户反馈在笔记的**新建模式**和**编辑模式**中，当切换到**预览模式**（Markdown 预览）时，编辑器操作按钮（`editorActionsBtn`，即齿轮图标按钮）应被隐藏，只有在 CM6 纯文本编辑模式下才显示。当前代码中 `switchEditorMode` 函数未处理按钮的显隐，导致预览模式下按钮仍然可见。

## 当前状态分析

### 相关文件

1. **`frontend/src/main.js`** — 核心逻辑：
   - `switchEditorReadOnly(readOnly)` (L209-260)：当切换到只读查看模式时，在 L220-221 将 `editorActionsBtn` 隐藏（`display: none`）。但此函数是用于「查看模式」而非「编辑/新建内的预览模式」。
   - `openEditor()` (L3706+)：在 L3738-3739 根据 `isReadOnly` 控制按钮显隐。
   - **`switchEditorMode(mode)` (L4632-4650)**：用于在编辑/新建流中切换「纯文本」和「预览」模式，**当前不涉及 `editorActionsBtn` 的显隐控制** — 这是问题根因。

2. **`frontend/src/js/editor-actions.js`** — 操作菜单逻辑：
   - `initEditorActionsMenu()` (L44-192)：初始化按钮和下拉菜单，不控制按钮显隐。

3. **`frontend/index.html`** (L183-186) — HTML 结构：
   - `editorActionsBtn` 位于 `.editor-header` 内，与 CM6 编辑器区域相互独立。

4. **`frontend/src/css/components/editor.css`** — 样式：
   - L260-275：预览模式下只隐藏了 `.editor-textarea`（CM6 容器），显示了 `.md-rendered`（渲染区）。
   - **没有**任何 CSS 规则在 `[data-mode="preview"]` 下隐藏 `editorActionsBtn` 或 `.editor-actions-wrap`。

### 问题根因

`switchEditorMode` 函数在切换编辑/预览模式时，只处理了视图切换（CM6 显示/隐藏、TOC 等），**没有处理 `editorActionsBtn` 的显隐**。导致在预览模式下，操作按钮仍然可见。

## 修改方案

### 修改 1：`frontend/src/main.js` — `switchEditorMode` 函数

在 `switchEditorMode` 函数中，根据模式切换操作按钮的显隐：

- 预览模式 → 隐藏 `editorActionsBtn`（`display: none`）
- 编辑模式 → 显示 `editorActionsBtn`（`display: ''`）

### 修改 2：`frontend/src/css/components/editor.css` — 添加 CSS 兜底规则（可选）

添加一条 CSS 规则，确保在预览模式下操作按钮隐藏（作为样式层面的兜底）：

```css
/* 预览模式下隐藏操作按钮 */
.editor-overlay[data-mode="preview"] #editorActionsBtn {
  display: none !important;
}
```

## 期望行为

| 模式 | 操作按钮 |
|------|---------|
| 编辑模式（纯文本） | 可见 |
| 预览模式（Markdown 渲染） | 隐藏 |
| 查看模式（只读） | 隐藏 |

## 验证步骤

1. 打开应用，新建一个 Markdown 笔记
2. 在编辑模式下，确认操作按钮（齿轮图标）可见
3. 点击「预览」模式按钮，确认操作按钮被隐藏
4. 切回「纯文本」模式，确认操作按钮重新显示
5. 同理测试编辑已有笔记的两种模式切换
6. 确认查看模式（只读）下操作按钮仍然隐藏
