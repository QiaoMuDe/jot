Core Features

核心特性

从笔记管理到 AI 助手，Jot 提供全方位的卡片式笔记体验

卡片式笔记网格

笔记本 → 笔记卡片 → 编辑器的三步交互范式，直观的文件夹-文件-编辑结构，让笔记管理一目了然。

AI 智能助手

支持 OpenAI 兼容（DeepSeek、通义千问等）与 Ollama 本地模型，流式输出 + 深度思考 + 12 项技能一键切换。

Markdown 编辑器

基于 CodeMirror 6 的专业编辑体验，支持行号、语法高亮、查找替换、全屏编辑，以及 TOC 目录侧栏自动生成。

14 套系统主题

从深色到浅色，从 Tokyo Night 到 Catppuccin，全局 CSS 变量联动，所有组件自动适配，代码高亮主题独立配置。

标签系统

自定义标签（名称 + 颜色），按标签筛选笔记，无限滚动标签选择器，支持批量添加/移除标签，灵活分类。

联网搜索

支持 Tavily 通用搜索、知乎搜索、全网搜索三个独立来源，可同时开启，AI 自动精化搜索词，获取最新信息。

数据管理

一键备份/还原完整数据（含图片）、数据库瘦身 VACUUM、回收站软删除、恢复出厂设置、8 项数据统计面板。

本地存储 · 安全无忧

所有数据存储在本地 SQLite 数据库中，无网络依赖。锁屏密码（SHA-256 哈希）、图片本地化管理，数据完全由你掌控。

异构文件导入

拖入 PDF、Word、Excel、PPT 等办公文件，内置 markitdown 引擎自动清洗转换为 Markdown，一键存为笔记，或直接交给 AI 助手分析。

File Import

异构文件清洗转换

PDF、Office 文档等异构文件，一键清洗转换为标准 Markdown，沉淀为知识库笔记，或直接交给 AI 助手分析

PDF DOCX XLSX XLS PPTX CSV EPUB IPYNB HTML RSS TXT · MD

一键导入

智能清洗

标题层级、表格、图片自动还原为规范 Markdown，保留内容结构

双通道输出
