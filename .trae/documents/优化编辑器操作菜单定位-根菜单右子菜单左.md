# 优化编辑器操作菜单定位：根菜单右展开 + 子菜单左展开（对开模式）

## 概述

编辑器操作按钮（齿轮图标）的下拉菜单定位不合理：根菜单向左展开、子菜单向右展开，导致子菜单与 header 其他按钮重叠。改为**对开模式**——根菜单向右展开、子菜单向左展开，互不干扰且视觉对称。

## 当前状态

### 当前定位（[editor.css:148-153](file:///d:/峡谷/Dev/本地项目/jot/frontend/src/css/components/editor.css#L148-L153), [editor.css:207-221](file:///d:/峡谷/Dev/本地项目/jot/frontend/src/css/components/editor.css#L207-L221)）

**根菜单**：`right: calc(100% + 4px)` → 向左展开
**子菜单**：`left: calc(100% + 4px)` → 向右展开

### 问题

按钮位于 header 右侧，根菜单向左展开合理，但子菜单向右展开会延伸到按钮区域，与操作按钮、目录按钮等重叠。

## 修改方案

### 改动：`frontend/src/css/components/editor.css`

只改两处定位属性，保持其他样式不变。

#### 1. 根菜单改为向右展开

```css
.editor-actions-menu.dropdown-menu {
  /* 修改前 */
  left: auto !important;
  right: calc(100% + 4px) !important;
  transform-origin: top right !important;

  /* 修改后 */
  left: 0 !important;
  right: auto !important;
  transform-origin: top left !important;
}
```

#### 2. 子菜单改为向左展开

```css
.editor-actions-menu .submenu {
  /* 修改前 */
  left: calc(100% + 4px);
  transform-origin: top left;

  /* 修改后 */
  right: calc(100% + 4px);
  left: auto;
  transform-origin: top right;
}
```

## 验证步骤

1. 打开应用，新建或编辑一个 Markdown 笔记
2. 点击操作按钮（齿轮图标），确认根菜单在按钮右侧正常展开
3. 鼠标悬停「格式化」分组，确认子菜单在左侧正常展开
4. 确认子菜单不与 header 其他按钮重叠
5. 确认菜单在面板内，不溢出
6. 点击操作项（如 JSON 格式化），确认功能正常
