CAPABILITIES

为记录与思考而生的卡片底座

从笔记管理到 AI 助手，Jot 提供全方位的卡片式笔记体验。

01 / 网格

卡片式笔记网格

笔记本 → 笔记卡片 → 编辑器的三步交互范式，直观的文件夹-文件-编辑结构，让笔记管理一目了然。

NOTEBOOK GRID
02 / AI

AI 智能助手

支持 OpenAI 兼容端点（DeepSeek、通义千问等），内置 Agent 自动调度工具完成任务，流式输出 + 深度思考 + 13 项技能 + 16 个内置工具，可反问确认、接入外部 MCP。

AGENT / MCP
03 / 编辑

Markdown 编辑器

基于 CodeMirror 6 的专业编辑体验，支持行号、语法高亮、查找替换、全屏编辑，以及 TOC 目录侧栏自动生成。

CODEMIRROR 6
04 / 检索

智能检索

向量语义召回 + 关键词检索双通道，笔记批量向量化，AI 回答基于你的笔记、完整片段注入、有据可依。

VECTOR + KEYWORD
05 / 标签

标签系统

自定义标签（名称 + 颜色），按标签筛选笔记，无限滚动标签选择器，支持批量添加 / 移除标签，灵活分类。

TAG SYSTEM
06 / 联网

联网能力

内置网页读取与 HTTP API 调用工具（带 SSRF 防护），支持自由接入外部 MCP 服务器扩展搜索能力，AI 自动获取最新信息。

WEB + HTTP + MCP
07 / 数据

数据管理

一键备份 / 还原完整数据（含图片）、数据库瘦身 VACUUM、回收站软删除、恢复出厂设置、8 项数据统计面板。

BACKUP / VACUUM
08 / 搜索

本地存储 · 安全无忧

所有数据存储在本地 SQLite 数据库中，无网络依赖。锁屏密码（SHA-256 哈希）、图片本地化管理，数据完全由你掌控。

LOCAL SQLITE
09 / 导入

异构文件导入

拖入 PDF、Word、Excel、PPT 等办公文件，内置 markitdown 引擎自动清洗转换为 Markdown，一键存为笔记，或直接交给 AI 助手分析。

PDF / DOCX / XLSX

SMART RECALL

让 AI 真正读懂你的笔记

向量语义召回 + 关键词检索双通道，让回答有据可依。

批量向量化 · 语义召回

数据管理一键批量向量化（全库 / 按笔记本 / 按笔记），sqlite-vec 本地向量库理解语义，模糊记得也能定位到笔记。

关键词检索

SQL 关键词模糊检索（标题 / 内容 LIKE），代码片段、专有名词等精确术语命中即召回，零丢失。

笔记优先回答

双通道结果合并去重排序，回答基于你的笔记，召回片段完整注入、无截断。

AGENT MODE

内置AI 智能体

内置 Agent 支持 Chat（纯对话）、Agent（自动调度工具）、Plan（先定计划再逐步执行）三种模式，由 AI 调度内置工具与外部 MCP 工具，完成笔记召回、数据整理、联网检索等复杂任务。

read_url http_request recall_notes json_validate json_extract manage_todo manage_notebook manage_tag manage_memory manage_note get_stats ask_user create_plan update_plan

16 个内置工具

管理笔记 / 待办 / 标签 / 笔记本、笔记召回、数据统计、JSON 处理、网页读取、HTTP 调用、长期记忆增删改查，Agent 按任务自动调度。

外部 MCP 扩展

设置页完整管理（CRUD + 开关 + 测试连接），全局连接池预热复用，断线自动重连，stdio / SSE / HTTP 三种传输。

主动反问确认

信息不足时向用户提问（单选 / 多选 / 自定义），按你的选择继续执行，关键操作可控。

工具精细化控制

每个内置工具和 MCP 工具均可单独启用 / 禁用，设置页一键管理，精细化控制 Agent 能力范围。

13 项 AI 技能

翻译、编程、写作、解题答疑、需求规格、润色、摘要、文案、工作总结、提示词、人物档案、角色扮演、深度研究，技能可叠加。

长对话 · 全局记忆空间

超窗口对话自动压缩为结构化摘要省 Token；另设跨会话全局记忆空间，可让 AI 记住 / 更新 / 遗忘长期偏好与事实并注入问答。

FILE IMPORT

异构数据一键清洗入库

PDF、Office 等异构文件一键清洗为标准 Markdown，沉淀为知识库笔记，或直接交给 AI 助手分析。

PDF DOCX XLSX PPTX CSV EPUB IPYNB HTML RSS TXT · MD

一键导入

拖拽即可批量导入，自动识别文件格式，无需手动转换。

智能清洗

标题层级、表格、图片自动还原为规范 Markdown，保留内容结构。

双通道输出

转换结果存为笔记沉淀知识库，或一键发送给 AI 助手分析。
