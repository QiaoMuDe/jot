# 更多菜单"展开侧栏"功能优化计划

## 摘要

在"更多"菜单中点击"展开侧栏"时，如果当前处于非笔记首页的页面，先跳转到笔记首页，再展开侧栏。如果已在笔记首页，则保持原有切换逻辑不变。

***

**2.** **`toggleSidebar()`** **函数** (main.js, line 6937-6952)

```javascript
async function toggleSidebar() {
    const sidebar = els.notebookSidebar;
    if (!sidebar) return;
    const wasCollapsed = sidebar.classList.contains('collapsed');
    const isCollapsed = sidebar.classList.toggle('collapsed');
    localStorage.setItem('jot_sidebar_collapsed', String(isCollapsed));
    if (wasCollapsed && !isCollapsed) {
        await loadNotebooks();       // 折叠→展开时刷新笔记本数据
    }
    updateSidebarMenuItem();
    updateNotebookSidebarToggleBtn();
}
```

**3.** **`switchView()`** **中侧栏自动折叠逻辑** (main.js, line 663-668)

```javascript
// 非网格视图自动折叠侧栏
if (view !== 'grid' && !els.notebookSidebar?.classList.contains('collapsed')) {
    els.notebookSidebar.classList.add('collapsed');
    localStorage.setItem('jot_sidebar_collapsed', 'true');
    updateSidebarMenuItem();
}
```

这意味着：

* 切换到非 grid 视图时，侧栏 **自动折叠**

* 切换到 grid 视图时，侧栏 **不受影响**（保持原有状态）

* 从非 grid 视图切回 grid 时，侧栏仍然是 **折叠** 状态

## 变更方案

### 需要修改的文件

**仅需修改** **`frontend/src/main.js`** 中更多菜单的 `sidebar-toggle` 点击处理逻辑 (line 5449-5450)。

### 修改内容

将当前逻辑：

```javascript
} else if (item.dataset.action === 'sidebar-toggle') {
    toggleSidebar();
}
```

改为：

```javascript
} else if (item.dataset.action === 'sidebar-toggle') {
    if (state.currentView !== 'grid') {
        // 先跳转到笔记首页
        state.searchKeyword = '';
        switchView('grid');
        resetPagination();
        loadNotes();
        // 非网格视图已将侧栏折叠，返回首页后将其展开
        if (els.notebookSidebar?.classList.contains('collapsed')) {
            els.notebookSidebar.classList.remove('collapsed');
            localStorage.setItem('jot_sidebar_collapsed', 'false');
            updateSidebarMenuItem();
            updateNotebookSidebarToggleBtn();
        }
    } else {
        // 已在笔记首页，保持原有切换逻辑
        toggleSidebar();
    }
}
```

### 逻辑说明

1. **非笔记首页**（如设置、回收站、日历、AI助手等页面）：

   * 先执行切换到 grid 视图的标准动作（`switchView('grid')` + `resetPagination()` + `loadNotes()`）

   * 非 grid 视图已自动折叠侧栏，所以切回 grid 后需手动展开

   * 展开操作复用 `toggleSidebar` 内部的核心展开逻辑（移除 `collapsed` class + 持久化 + 更新UI）

2. **已在笔记首页**：

   * 保持原有 `toggleSidebar()` 切换行为不变

### 为什么不直接调用 `toggleSidebar()`

在非笔记首页切回 grid 时，侧栏已确定是折叠状态。`toggleSidebar()` 会翻转折叠/展开状态（如果未折叠则会折叠），而我们的需求是 **确保展开**。使用明确的展开逻辑更可靠，且避免了 `loadNotebooks()` 的重复调用（`loadNotes()` 已触发数据加载）。
