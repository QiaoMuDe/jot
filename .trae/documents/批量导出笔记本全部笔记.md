# 批量导出笔记本全部笔记（导出到"笔记本名/"子目录）

## 摘要

笔记本右键菜单新增「导出全部笔记」：后端新增 `ExportNotebookAsMarkdown(notebookID)`——选择父目录 → 用笔记本名新建子目录 → 将该笔记本下所有笔记及其引用的图片全部导出到子目录内平铺。复用单条导出的图片处理逻辑（抽取为公共函数），保持 `.md + 同名 .assets/` 结构与图片原始文件名，导入闭环不受影响。

## 现状分析

- **后端单条导出** [ExportNoteAsMarkdown](file:///d:/峡谷/Dev/本地项目/jot/app.go#L3343-L3433)：图片处理逻辑内联（仅 .md、title 拆分、复制到 `filePath+".assets"`、改写相对路径、防路径穿越），P1-P7 已修复
- [sanitizeFilename](file:///d:/峡谷/Dev/本地项目/jot/app.go#L3528-L3556)：可复用清理子目录名与文件名（非法字符替换为 `_`）
- **笔记本右键菜单** [showNotebookContextMenu](file:///d:/峡谷/Dev/本地项目/jot/frontend/src/main.js#L7728-L7791)：仅「重命名」「删除」两项，已有按压回弹/淡出关闭逻辑
- **Notebook 模型**：`ID` / `Name` / `DeletedAt`；无现成 GetByID，校验用 `a.db` 直查（App 层直查 db 有先例，如 `deleteImagesIfUnreferenced`）
- **无现成** `fileExists` 函数、无 `SaveDirectoryDialog` 使用先例（Wails 标准 API，可用）

## 改动方案

### 后端 [app.go](file:///d:/峡谷/Dev/本地项目/jot/app.go)

**1. 新增公共函数 `exportNoteContentWithImages(note *models.Note, targetPath string) (content string, exported, missing int)`**
- 从 `ExportNoteAsMarkdown` 抽取图片处理逻辑（.md 限定、title 拆分、复制到 `targetPath+".assets"`、改写为相对路径）
- 不负责写文件，由调用方决定目标路径

**2. 重构 `ExportNoteAsMarkdown`**：SaveFileDialog 选路径后调用公共函数，再 `os.WriteFile`，行为不变

**3. 新增 `fileExists(path string) bool`**（`os.Stat` 封装）

**4. 新增 `ExportNotebookAsMarkdown(notebookID uint) (string, error)`**：
1. 校验笔记本存在：`a.db.Where("id=? AND deleted_at IS NULL").Take`，不存在报错
2. 查全部未删除笔记（含 content）：`a.db.Where("notebook_id=? AND deleted_at IS NULL").Find`；空 → 返回"该笔记本下没有笔记"（不弹目录）
3. `runtime.SaveDirectoryDialog` 选父目录；空 → 返回"已取消"
4. `os.MkdirAll(filepath.Join(parentDir, sanitizeFilename(notebook.Name)), 0755)` 建子目录
5. 逐篇导出：文件名 = `sanitizeFilename(标题)+FileExt`，子目录内重名追加序号 `(2)(3)...`（`.assets` 随 md 同名联动）→ 调公共函数 → `os.WriteFile`；单篇失败记日志计数，不中断
6. 返回汇总消息（成功/失败数、图片数）

### 前端 [main.js](file:///d:/峡谷/Dev/本地项目/jot/frontend/src/main.js)

**5. 菜单加「导出全部笔记」项**（[L7740](file:///d:/峡谷/Dev/本地项目/jot/frontend/src/main.js#L7740) 重命名之后、删除之前）：
- `data-action="export"`，feather download 风格 svg 图标，与现有菜单项样式一致

**6. 点击分支**（[L7783](file:///d:/峡谷/Dev/本地项目/jot/frontend/src/main.js#L7783) 处）加：
```js
} else if (action === 'export') {
```

## 假设与决策

- 子目录名 = `sanitizeFilename(笔记本名)`；重复导出覆盖同名 md（内容一致无感），旧孤儿图片保留不清理
- 子目录内笔记重名 → 追加序号
- 同步调用 + 汇总提示，不做异步进度事件（个人笔记量级小）
- 图片处理与单条导出完全一致，不引入新逻辑

## 验证步骤

1. `go build ./...` 编译通过
2. 手动：右击笔记本 → 导出全部笔记 → 选父目录 → 确认生成 `笔记本名/` 子目录，内含全部 `.md` 平铺 + 同名 `.assets/` 图片；引用为相对路径；重名笔记带序号
3. 空笔记本：直接提示"该笔记本下没有笔记"，不弹目录
4. 取消：返回"已取消"，前端不弹成功提示
5. 单条导出回归：行为与修改前一致（含图片/不含图片/取消）
