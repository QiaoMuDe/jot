# 统一"向量嵌入"命名计划（去除"量化"错误叫法）

## Summary

项目中的"量化"（quantization）实为"向量嵌入"（embedding）：后端 `vector_service.go` 做的是 切块 → embedding 向量化 → 存 sqlite-vec。现按已确认的命名方案，把用户可见文案、后端错误消息、代码注释中的"量化"统一改为"向量嵌入/向量化/嵌入"，标识符与历史文档不动。
