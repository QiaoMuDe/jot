# 删除预设无需全量重渲染

## 问题

`deleteProfile` 中删除动画播完后，调用了 `renderPresetMgrList()`（[main.js#L3021-L3023](file:///d:/峡谷/Dev/本地项目/jot/frontend/src/main.js#L3021-L3023)）。这个函数执行 `presetMgrContainer.innerHTML = ''`（[main.js#L3055](file:///d:/峡谷/Dev/本地项目/jot/frontend/src/main.js#L3055)）将整个管理列表清空，然后逐行重建并播放入场动画（`preset-row-enter` + stagger 延迟）。视觉效果：被删除的行刚滑出消失，所有剩余行突然闪一下又重新弹出。

## 方案

删除动画播完 + 后端删除成功后，不要全量重渲染，只从 DOM 中移除已播放完删除动画的 `rowEl` 即可。

```javascript
// before
await window.go.main.App.DeleteProfile(id);
nm.show('配置已删除', 'success');
await loadProfiles();
if (presetMgrExpanded && presetMgrContainer && presetMgrContainer.parentNode) {
    renderPresetMgrList();  // ← 全量重渲染，导致闪烁
}

// after
await window.go.main.App.DeleteProfile(id);
nm.show('配置已删除', 'success');
await loadProfiles();
// 仅移除已播放删除动画的行，避免全量重渲染的闪烁
if (rowEl && rowEl.parentNode) {
    rowEl.remove();
}
```

为什么 `rowEl.remove()` 就够用了：
- `rowEl` 已经播完 `preset-delete-out` 动画（300ms），最终状态是 `opacity: 0; max-height: 0; padding: 0`，视觉上已消失
- 移除这个不可见的 DOM 节点不会产生任何视觉变化
- 管理列表中剩余的其他行保持原样，没有闪烁
- `loadProfiles()` 已经刷新了下拉菜单的选中态，需要切换预设的话也已经在里面处理了

## 影响范围

仅修改 [main.js](file:///d:/峡谷/Dev/本地项目/jot/frontend/src/main.js) 中 `deleteProfile` 函数的第 3021-3023 行，约 3 行代码替换。

无需改动后端、CSS 或其他任何文件。

## 验证步骤

1. 打开设置页 → API 链接 → 点击"管理"展开预设管理列表
2. 点击某个非默认预设的"删除"按钮
3. 确认弹出框
4. 观察：被删除行向右滑出消失 → 其余行保持原位，无闪烁无重新入场动画
5. 验证下拉菜单的选中态正确更新
