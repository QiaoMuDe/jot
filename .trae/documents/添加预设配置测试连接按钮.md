# 添加预设配置测试连接按钮

## Summary

在预设新增/编辑弹窗的 footer 中添加「测试连接」按钮，复用 API 连接页已有 `btn-loading` 动画和 `setBtnLoading` 模式。后端新增 `TestAIConnection` 绑定方法支持按 provider/baseURL/apiKey 参数独立测试（不依赖当前激活配置）。

## 当前状态

- **预设弹窗 footer**：`<div class="preset-modal-footer">` 仅有 `[取消]` 和 `[保存]` 两个按钮
- **测试参照**：API 地址行的「测试 URL」按钮使用 `setBtnLoading` + `btn-loading` 样式（spinner SVG + btnPulse 呼吸动画）
- **后端测试**：现有的 `TestAIBaseURL(baseURL, apiKey string)` 从 `GetConfig()` 取 provider，不适合独立预设测试

## 修改方案

### 1. `app.go` — 新增 `TestAIConnection` 绑定

在 `TestAIBaseURL`、`TestTavilyConnection`、`TestZhihuConnection` 附近新增方法：

```go
// TestAIConnection 测试指定 AI 配置的连通性（预设使用）
func (a *App) TestAIConnection(provider, baseURL, apiKey string) (bool, error) {
    cfg := services.AIConfig{Provider: provider, BaseURL: baseURL, APIKey: apiKey}
    result, err := a.aiService.TestConnection(cfg)
    ...
    return result, nil
}
```

- 直接构造 `AIConfig`，不依赖当前配置
- 复用 `AIService.TestConnection` 已有的三个分支（openai/ollama/generic）
- 超时等行为完全沿用现有逻辑

### 2. `frontend/index.html` — 预设弹窗 footer 新增按钮

在 `#presetModalCancel` 和 `#presetModalSave` 之间插入：

```html
<button class="btn btn-sm btn-save" id="presetModalTestBtn">测试连接</button>
```

- 使用 `btn-sm btn-save` 保持与「测试 URL」按钮一致的视觉风格
- 通过自身的 `setBtnLoading` 切换 loading 态，与 API 连接页测试按钮行为一致

### 3. `frontend/src/main.js` — 绑定事件与交互逻辑

**a) 新增元素引用（约 L540 附近）：**

```js
presetModalTestBtn: $('presetModalTestBtn'),
```

**b) 新增 `testPresetConnection` 函数或内联事件（在 `savePresetModal` 附近）：**

- 收集 modal 内字段值：service 商（`#presetModalProviderDropdown .active` 的 `data-preset-provider`）、API 地址（`#presetModalURL`）、API Key（`#presetModalKey`）
- 校验：API 地址为空时 `nm.show` 提示警告
- 调用 `setBtnLoading(btn, true, '测试中…')`
- 调用 `window.go.main.App.TestAIConnection(provider, baseURL, apiKey)`
- 成功 → `nm.show('连接成功', 'success')` / 失败 → `nm.show('连接失败: ' + e, 'error')`
- finally → `setBtnLoading(btn, false)`

**c) 在事件注册区（约 L2766-L2768 附近）新增：**

```js
document.getElementById('presetModalTestBtn')?.addEventListener('click', testPresetConnection);
```

## 交互与视觉

- 按钮样式：`btn btn-sm btn-save`，与「测试 URL」按钮保持一致
- 加载态：`setBtnLoading` 注入 spinner SVG + `btn-loading` class（pulse 动画 + pointer-events: none）
- 测试结果：通过 `nm.show()` 显示 success / error 通知
- 测试期间按钮 disabled，用户无法重复点击

## 未涉及

- 管理列表（`renderPresetMgrList`/`createPresetRowElement`）不修改
- 预设下拉选择行不修改
- 后端 `TestAIBaseURL` 不修改（保持向后兼容）
