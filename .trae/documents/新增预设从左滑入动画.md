# 新增预设从左滑入动画

## 需求

目前新增预设配置时，新行以 `preset-row-enter` 动画（从上方 6px 淡入并缩放）出现。希望改成从左侧滑入，与删除时向右滑出的动画形成视觉呼应：**删除向右滑走，新增从左滑进来**。

## 方案

### 1. CSS：新增从左滑入动画

在 [settings-panel.css](file:///d:/峡谷/Dev/本地项目/jot/frontend/src/css/components/settings-panel.css) 的 `presetRowEnter` 定义之后追加：

```css
/* 新增预设行从左滑入动画（与删除滑出方向呼应） */
.preset-row-enter-left {
    animation: presetRowEnterFromLeft 300ms ease-out both;
}

@keyframes presetRowEnterFromLeft {
    from {
        opacity: 0;
        transform: translateX(-30px);
    }
    to {
        opacity: 1;
        transform: translateX(0);
    }
}
```

- 300ms `ease-out`：与删除的 `ease-in` 互为镜像，到达终点时平缓减速
- 从 `translateX(-30px)` 开始（左侧 30px），到原位结束
- 不涉及 `max-height`/`padding` 变化（初始渲染时行已有完整高度，不需要空间展开效果）

### 2. JS：新增行时使用新动画类

在 [main.js](file:///d:/峡谷/Dev/本地项目/jot/frontend/src/main.js) 的 `savePresetModal` 中，创建新行后将动画类替换为 `preset-row-enter-left`：

```javascript
// 当前（main.js #L2999）
const row = createPresetRowElement(profile);

// 改为：
const row = createPresetRowElement(profile);
row.classList.remove('preset-row-enter');
row.classList.add('preset-row-enter-left');
```

`createPresetRowElement` 内部固定添加 `preset-row-enter`（全量渲染时也用它，保持上方淡入效果），新增场景只需在外部替换类名即可，不影响 `renderPresetMgrList` 的初始加载动画。

### 3. 无需改动的部分

- `renderPresetMgrList` 中的全量列表渲染继续使用 `preset-row-enter`（从上方淡入），仅单行新增场景使用从左滑入
- 删除动画 `preset-delete-out` 完全不变
- 后端、HTML 均无改动

## 最终视觉效果

| 操作 | 动画 | 方向 |
|------|------|------|
| 删除预设 | `presetDeleteOut` 300ms | 向右滑出 → 消失 |
| 新增预设 | `presetRowEnterFromLeft` 300ms | 从左侧滑入 → 到位 |
| 全量列表渲染 | `presetRowEnter` 300ms | 从上方位移淡入（保持现状） |

新增和删除形成方向上的对称：**从左来，往右走**。

## 验证步骤

1. 打开设置页 → API 链接 → 展开管理列表
2. 点击"新增"并保存一个新预设
3. 观察新行从左侧滑入，与删除的向右滑出形成呼应
4. 确认全量渲染（初次展开列表）时仍使用上方淡入动画，不受影响
